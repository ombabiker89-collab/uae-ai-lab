## Why this exists

The UAE stack is moving fast — Falcon (TII), Jais (Inception + MBZUAI), K2 Think, sovereign compute, and agentic government services. Most public work is scattered across orgs. This repo is a working board to:

1. Scout official and open-weight code (`tiiuae`, MBZUAI NLP, Jais cards).
2. Package services that local buyers actually buy (Arabic agents, resident inference, dialect packs, eval).
3. Bridge dialect data — including [sudanese-dialect-corpus](https://github.com/ombabiker89-collab/sudanese-dialect-corpus) — into Jais/Falcon fine-tune paths.
4. Keep PDPL and data-residency notes next to the code, not in a slide deck.
