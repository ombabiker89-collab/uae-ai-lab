# Contributing

## Flow

1. Open an issue using the scout / service template.
2. Branch from `main` — `scout/<topic>`, `svc/<service>`, `model/<family>`, `bridge/<dialect>`.
3. Small PRs. Arabic + English in user-facing docs.
4. No secrets. No scraped personal data. No fake official logos or partnership claims.

## Commit style

`type(scope): summary`

Types — `feat` `fix` `docs` `data` `model` `scout`  
Scopes — `uae` `arabic` `falcon` `jais` `g42` `pdpl` or a sector.

## Review bar

- Does this help a UAE buyer, researcher, or Arabic speaker?
- Is the model family named with origin (TII / Inception / MBZUAI)?
- Is there a one-line residency / PDPL note?
